怎么拿到 UUID 和伪装域名？（部署自带 worker.js）

先记住一件事：本工具只负责把 IP 列表拼成配置文件，不提供线路。服务端用配套的 worker.js，部署在 Cloudflare 上，免费且最省事。部署完打开域名，页面会直接显示「伪装域名」和「UUID」。

① 生成 UUID（相当于账号密码）

  1. 打开 https://www.uuidgenerator.net/，复制第一行的 v4 UUID；电脑上也可以执行 uuidgen。
  2. 格式是 8-4-4-4-12 共 36 个字符，例如 3f2a1b4c-8d5e-4f6a-9b7c-1d2e3f4a5b6c。
  3. 这串会用在两个地方：Worker 代码和本工具的「UUID」输入框，必须完全一致。

② 在 Cloudflare 部署 worker.js

  1. 登录 dash.cloudflare.com，左侧 Workers & Pages → Create → Worker。
  2. 名字随便取，例如 my-node，点 Deploy。
  3. 点 Edit code，把编辑器里的示例代码全选删掉。
  4. 粘贴 worker.js 的全部内容。
  5. 找到 uuid: "00000000-0000-0000-0000-000000000000"，换成第 ① 步生成的 UUID。
  6. 点 Deploy。

不想把 UUID 写死在代码里，也可以在 Worker 的 Settings → Variables 里添加 UUID 变量。

One thing first: this tool only assembles your IP list into a config file. It provides no routes. The server is the bundled worker.js, deployed on Cloudflare — free and the least hassle. Once deployed, open the domain and the page shows the disguise domain and the UUID.

1. Generate a UUID (your account password)

  1. Open https://www.uuidgenerator.net/ and copy the first v4 UUID, or run uuidgen on a computer.
  2. The format is 8-4-4-4-12, 36 characters, e.g. 3f2a1b4c-8d5e-4f6a-9b7c-1d2e3f4a5b6c.
  3. The same string is used in two places: the Worker code and the UUID field in this tool. They must match exactly.

2. Deploy worker.js on Cloudflare

  1. Sign in at dash.cloudflare.com, open Workers & Pages → Create → Worker.
  2. Pick any name, e.g. my-node, then press Deploy.
  3. Press Edit code and delete the sample code.
  4. Paste the entire contents of worker.js.
  5. Find uuid: "00000000-0000-0000-0000-000000000000" and replace it with the UUID from step 1.
  6. Press Deploy.

If you would rather not hard-code it, add a UUID variable under the Worker's Settings → Variables.

3. Open the domain and copy both values

  2. Convert, import into the client and run a latency test. A number means it connects.
  3. Open ip.sb and confirm the exit IP changed.
