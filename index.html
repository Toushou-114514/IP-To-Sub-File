怎么拿到 UUID 和伪装域名？（Cloudflare 方式）

先记住一件事：本工具只负责把 IP 列表拼成配置文件，它不提供任何线路。你必须先有一个服务端，Cloudflare Worker 是最省事的免费方案。下面的 UUID 和伪装域名，都来自那个服务端。

① 生成 UUID（相当于账号密码）

  1. 打开 https://www.uuidgenerator.net/，第一行的 v4 UUID 直接复制；电脑上也可以执行 uuidgen。
  2. 格式是 8-4-4-4-12 共 36 个字符，例如 3f2a1b4c-8d5e-4f6a-9b7c-1d2e3f4a5b6c。
  3. 这串要同时出现在两个地方：服务端（Worker 代码里）和本工具的「UUID」输入框，必须一模一样。
  4. 不要用本工具自动生成的那串占位值，服务端不认识它，连接一定失败。

② 在 Cloudflare 部署 Worker

  1. 登录 dash.cloudflare.com，左侧选 Workers & Pages → Create → Worker。
  2. 名字随便取，例如 my-node，创建后点 Edit code。
  3. 把现成的 Worker 脚本粘进去（GitHub 上搜 cmliu/edgetunnel，选它的 worker.js），替换掉编辑器里的示例代码。
  4. 在代码里找到 let userID = '...'，改成你第 ① 步生成的 UUID；路径一般是 url.pathname === '/?ed=2048' 这类判断，记下来。
  5. 点 Deploy，等十几秒，页面会给一个地址：https://my-node.用户名.workers.dev。

③ 从地址里取出伪装域名

上面那个地址去掉 https:// 和结尾的斜杠，剩下的就是伪装域名：

Worker 地址https://my-node.abc.workers.dev/
伪装域名my-node.abc.workers.dev
SNI同一个值（本工具已合并成一个输入框）

如果你给自己域名绑了橙色云朵（Proxied）并指向 Worker，就用那个域名，例如 cdn.example.com。

⑤ 验证是否配对

  1. 浏览器打开 https://伪装域名/路径，能打开（哪怕是 404 页面）说明域名和 Worker 正常。
  2. 路径正确时，用普通浏览器访问通常返回 400 Bad Request 或 426 Upgrade Required，这是 WebSocket 端点的正常反应。
  3. 都是 404 说明路径写错了，回到 Worker 代码里核对。

⑥ 报错对照

现象多半是
超时伪装域名或端口错；域名没走 Cloudflare；Worker 没部署成功
失败 / 连接被关闭UUID 和服务端不一致，或 WS 路径不对
404WS 路径错误
证书错误伪装域名填成了优选 IP

UUID 加域名相当于你的账号密码，截图或分享时记得打码。Worker 免费版每天大约 10 万次请求，轻度使用足够。
